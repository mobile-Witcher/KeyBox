# KeyBox 鸿蒙版 · 成员安装指南（小白助手自签）

> 面向拿到 KeyBox 鸿蒙安装包的成员。**全程不用写代码**，照着点就行，熟练后约 1 分钟。

---

## 为什么需要这一步？

鸿蒙 NEXT 出于安全考虑，不允许随手安装未上架的应用。要装到自己的设备上，需要用华为官方工具给安装包**签个名**——可以理解为"盖一个允许在我这台设备上运行的章"。这个章只对你自己的设备有效，不影响 KeyBox 本身的加密安全。

---

## 一、一次性准备（只需要做一次）

### 1. 注册华为开发者账号（免费）

1. 打开 <https://developer.huawei.com> → 注册账号
2. 完成**实名认证**（个人实名即可，通常几分钟到几小时通过）

> 这是免费的，也是唯一可能需要等待的环节。完成之后，以后每次 KeyBox 更新都不用再重复。

### 2. 电脑上装「小白调试助手」

华为生态里常用的官方签名安装工具，网上搜"小白调试助手"即可找到，按提示装好。

---

## 二、安装 KeyBox（每次版本更新都要做一次，约 1 分钟）

### 第 1 步：下载安装包

从管理员给你的链接下载 **`entry-default-unsigned.hap`**（名字里带 `unsigned`，就是待签名安装包）。

### 第 2 步：手机开启 USB 调试并连电脑

1. 手机：**设置 → 关于本机 → 连点"版本号" 7 次**（会提示已进入开发者模式）
2. **设置 → 系统与更新 → 开发者选项 → 打开"USB 调试"**
3. 用**数据线**（不是纯充电线）把手机连到电脑
4. 手机弹出「是否允许 USB 调试？」→ 勾选"一律允许" → 点**允许**

### 第 3 步：一键签名安装

1. 电脑上打开**小白调试助手** → 登录你的华为开发者账号
2. 点「**调试**」→ 选择刚才下载的 `.hap` 文件
3. 工具自动完成签名并安装到你的手机

### 第 4 步：打开

手机桌面出现 KeyBox 图标 → 点开 → 手机号登录 → 设主密码 → 开始使用。

---

## 三、常见问题

| 现象 | 原因与处理 |
|---|---|
| 提示「已存在 / install already exist」 | 已装过旧版 KeyBox。先**卸载**旧版，再重新签名安装 |
| 助手读不到设备 | 换数据线或换 USB 口；重新开关一次 USB 调试；手机保持亮屏解锁 |
| 提示证书/Profile 相关错误 | 通常是华为账号实名未通过，或助手需要重新登录一次 |
| 过一段时间打不开了 | 调试证书有有效期，重走一遍安装步骤即可（数据不会丢） |
| 装不了 / 不想折腾 | 直接用**网页版**（手机或电脑浏览器打开，功能完全一致） |

---

## 四、重要说明

- **签名只影响"能不能装到你的设备上"，不影响 KeyBox 的加密强度**。你的密钥依然是端到端加密：云端只见密文，主密码只在你的脑子里和本机内存中。
- 换手机、重装系统后：重走一遍安装流程即可，账号与数据都在（手机号登录 + 主密码解锁）。
- 你与其他成员的数据**完全隔离**，互相看不到；管理员也只能删除账号，看不到任何明文内容。
