# KeyBox 鸿蒙版 · 成员接入指南（管理员统一签名模式）

> 模式说明：管理员（你）用自己的华为开发者账号统一签名。成员**不需要**注册华为开发者账号。
> 每台设备只需完成一次"UDID 登记"，之后由管理员签发安装包。

---

## 第一部分：发给成员的话（直接转发下面这段）

---

**【KeyBox 安装指南（HarmonyOS）】**

第 1 步：把《member-kit.zip》解压到电脑（Windows）。

第 2 步：用**数据线**把你的鸿蒙手机/平板连上电脑。

第 3 步：手机上开启 USB 调试：
- 设置 → 关于本机 → 连点"版本号"7 次（开启开发者模式）
- 设置 → 系统与更新 → 开发者选项 → 打开「USB 调试」
- 连接时手机弹窗「是否允许 USB 调试？」→ 勾选"一律允许" → 允许

第 4 步：双击运行《获取设备UDID.bat》。
屏幕会显示一行 64 位的字符串（UDID）。

第 5 步：把这串 UDID **复制发给管理员**（魏智智）。

第 6 步：等待管理员发回《KeyBox 安装包》（.hap 文件）+ 安装工具。

第 7 步：收到后，把 hap 和 hdc.exe 放同一文件夹，电脑命令行执行：
```
hdc.exe install -r KeyBox.hap
```
（或等管理员指导）安装完成，手机桌面出现 KeyBox。

## 第二部分：管理员操作手册（你自己）

### A. 收到成员 UDID 后：登记设备

1. 打开华为 **AppGallery Connect**：https://developer.huawei.com/consumer/zh/service/josp/agc/index.html
2. 用你的开发者账号登录
3. 进入「**我的项目**」→ 选择 KeyBox 所在项目 → 进入应用 **KeyBox**（bundleName: com.jidongzhanshi.keybox）
4. 左侧「**HarmonyOS 应用调试**」或「证书、APP ID 与 Profile」→ **「设备」管理**（调试设备列表）
5. 点「**添加设备**」→ 名称填成员名字（如 zhangsan-pad）→ UDID 粘贴那串 64 位字符串 → 保存
6. 进入「**Profile**」（调试 Profile，DevEco 自动生成的那个）→ **重新生成/下载**（让 Profile 包含新设备）

> 注意：调试 Profile 绑定的设备数量有上限（AGC 一般为 100 台内），20 人规模完全够用。

### B. 重新签名并分发

1. 打开 DevEco Studio → 打开 KeyBox-harmony 工程
2. **File → Project Structure → 签名配置**：确认 Profile 是**最新版**（含新设备）。
   若勾选了自动生成签名，点一次「确定」它会自动拉取最新 Profile
3. 顶部绿色 **▶ 运行**（先自己验证一遍），或菜单 Build → 构建 HAP
4. 取产物：`entry/build/default/outputs/default/entry-default-signed.hap`
5. 把这个 **signed.hap + hdc.exe**（在 distribution/member-kit 里有）发给成员
6. 成员侧安装：命令行 `hdc.exe install -r KeyBox.hap`

### C. 以后每次更新版本

代码改完 → DevEco 构建出 signed.hap → 发群里 → 成员跑一次 `hdc.exe install -r 新包.hap`
（设备 UDID 已登记过，不需要重复第 A 部分）

## 第三部分：重要注意事项

1. **调试证书/Profile 有有效期**（AGC 默认一般 1 年内），到期后需在 AGC 重新生成并重签重装
   —— 到期现象：应用突然无法打开/启动闪退。处理：AGC 重新生成 Profile → DevEco 重签 → 重装
2. **你的 keybox.p12（keystore 文件夹里）是"发布签名"身份**，与调试签名是两回事。
   将来上架应用市场时用它。**务必备份**。
3. 成员的设备 UDID 属于设备标识，登记表（谁名下哪台设备）建议留档，方便日后管理停用。
4. 成员超过 20 人？调试设备上限一般 100 台，但你的产品上限就是 20 人，无冲突。
