KeyBox Windows 0.5.0 —— 免安装压缩包版

【怎么用】
1. 把整个文件夹解压到任意目录（例如 D:\KeyBox）。
2. 双击 KeyBox.App.exe 即可运行；建议创建桌面快捷方式。
3. 无需导入任何证书、无需管理员权限；不写注册表，卸载 = 删文件夹。
4. 本版已内置 Windows App SDK 运行时，目标机无需安装任何东西。

【重要】不要只把 exe 拖出来单独运行——必须保持文件夹结构完整，
且从本文件夹内启动（非打包 WinUI 3 应用依赖同目录的 resources.pri 与 Assets\）。

【数据位置】
设置/会话/窗口状态保存在 %APPDATA%\KeyBox\（删除该目录即恢复初始状态）。
主密码与主密钥永不离开设备；云端只保存密文。

【与 MSIX 版的区别】
MSIX 需要为每台电脑导入自签名证书才能安装；压缩包版没有这个前置条件，推荐内部分发。
