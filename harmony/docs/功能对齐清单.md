## Web 独有（有意不对齐）

- 管理员后台（邀请码生成/用户管理/全局统计）—— 管理操作统一走 Web
- 安全面板全部敏感操作（改主密码/轮换密钥/恢复码）
- 项目设置、皮肤管理等一次性配置动作
